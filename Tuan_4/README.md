## Yêu cầu môi trường
- Hệ điều hành: Windows / Linux / macOS
- C/C++ compiler hỗ trợ C99 hoặc mới hơn
- CMake: phiên bản 3.20 (khuyến nghị)

## Hướng dẫn build and run
- git clone https://github.com/pdd04/CTD.git
- cd CTD
- mkdir build
- cd build
- cmake ..
- cmake --build .
- cd Tuan_4
- ./symtab.exe
